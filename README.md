# Daymark — To-Do & Notes Workspace

A calm, responsive productivity app for tasks, notes, and focused work. Built entirely with AI for the assignment requirements.

## Features

- Task creation, priorities, due dates, completion, deletion, and search
- Today, upcoming, all-task, and completed views
- Colour-coded notes
- Focus timer with accumulated focus minutes
- Progress dashboard and dark mode
- Browser persistence with safe localStorage normalization
- Responsive, accessible interface

## Run locally

```bash
npm test
npm run check
npm run dev
```

No build step or database is required. Vercel serves the repository as a static web application.
